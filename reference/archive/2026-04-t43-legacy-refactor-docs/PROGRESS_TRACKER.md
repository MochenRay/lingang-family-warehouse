### 可用的 CSS 变量
现在可以在任何组件中使用：
```css
/* 色彩 */
var(--color-brand-primary)      /* #2761CB */
var(--color-brand-primary-hover) /* #4E86DF */
var(--color-neutral-02)          /* #1F293A */
var(--color-text-primary)        /* #AEC0DE */

/* 圆角 */
var(--radius-xs)   /* 2px */
var(--radius-s)    /* 4px */
var(--radius-m)    /* 8px */

/* 阴影 */
var(--shadow-01)   /* 浮层阴影 */
var(--shadow-02)   /* 悬浮阴影 */
var(--shadow-03)   /* 模态窗阴影 */

/* 字体 */
var(--text-sm)     /* 14px */
var(--line-sm)     /* 22px */

/* 间距 */
var(--spacing-lg)  /* 16px */
var(--spacing-xl)  /* 24px */
```

### 可用的 Tailwind 类名（通过 @theme inline）
```html
<!-- 主色调 -->
<button class="bg-blue hover:bg-blue-hover">按钮</button>

<!-- 功能色 -->
<div class="text-success">成功</div>
<div class="text-error">错误</div>

<!-- 背景 -->
<div class="bg-bg-2">卡片</div>

<!-- 文字 -->
<p class="text-text-primary">主要文字</p>
<p class="text-text-secondary">次要文字</p>
```

### 影响范围
- ✅ 不影响现有功能（只添加新变量）
- ✅ 兼容现有 shadcn/ui 组件（保留了原有变量）
- ✅ 为后续组件调整奠定基础

### 验证建议
1. 打开浏览器开发工具 → Elements → Computed
2. 查看 `:root` 样式，确认变量已定义
3. 尝试在任意组件中使用新变量，验证是否生效
