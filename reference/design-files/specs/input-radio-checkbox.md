## 一、单选（Radio）

### 设计说明
当选项过少，用户产生从选项中选择一个选项。

### 组件特点
- **形状**：圆形按钮
- **选择类型**：单选（互斥）
- **适用场景**：选项较少，用户只能选择一个选项

---

### 状态设计

#### 1. 基本用法

**未选中（Default）**
- **外圈**：灰色圆圈边框
- **内圈**：空心（无填充）
- **边框色**：约 `#546789`（辅助文字色）或类似
- **尺寸**：约 16px × 16px（预估）
- **文字色**：`#A6C0CE`（主要文字）

**选中（Selected）**
- **外圈**：蓝色圆圈边框
- **内圈**：蓝色实心圆点
- **边框色**：`#2761CB` (Blue-06)
- **填充色**：`#2761CB` (Blue-06)
- **内圆大小**：约占外圈的 50-60%
- **文字色**：`#2761CB`（蓝色，表示激活）

**悬停（Hover）**
- 外圈颜色略微变亮
- 或添加背景高亮效果

---

#### 2. 禁用状态

**已选禁用（Selected Disabled）**
- **外圈**：灰色圆圈边框
- **内圈**：灰色实心圆点
- **边框色**：约 `#546789` 或更暗
- **填充色**：约 `#546789` 或更暗
- **文字色**：`#546789`（辅助文字色，表示禁用）
- **光标**：not-allowed

**未选禁用（Disabled）**
- **外圈**：灰色圆圈边框（更暗）
- **内圈**：空心
- **边框色**：约 `#546789` 或更暗
- **文字色**：`#546789`（辅助文字色）
- **光标**：not-allowed

---

### 设计规范（从图片观察）

| 属性 | 未选中 | 选中 | 已选禁用 | 未选禁用 |
|------|--------|------|---------|---------||
| **外圈颜色** | #546789 | #2761CB | #546789 | #546789 |
| **内圈填充** | 无 | #2761CB | #546789 | 无 |
| **文字颜色** | #A6C0CE | #2761CB | #546789 | #546789 |
| **尺寸** | 16px | 16px | 16px | 16px |
| **边框宽度** | 1-2px | 1-2px | 1-2px | 1-2px |

---

### 布局规范

- **文字与按钮间距**：约 8px
- **选项之间间距**：约 24-32px（横向排列）
- **垂直间距**：约 16px（纵向排列）

## 二、复选框（Checkbox）

### 设计说明
当选项过多，用户从选项中选择多个选项。

### 组件特点
- **形状**：方形复选框
- **选择类型**：多选（可同时选择多个）
- **适用场景**：选项较多，用户可以选择多个选项
- **特殊状态**：支持半选（indeterminate）状态

---

### 状态设计

#### 1. 基本用法

**未选中（Default）**
- **形状**：方形边框
- **填充**：无（空心）
- **边框色**：约 `#546789`（辅助文字色）或类似
- **尺寸**：约 16px × 16px（预估）
- **圆角**：小圆角（约 2-3px）
- **文字色**：`#A6C0CE`（主要文字）

**选中（Checked）**
- **形状**：方形
- **填充**：蓝色背景
- **背景色**：`#2761CB` (Blue-06)
- **图标**：白色对勾 ✓
- **图标色**：`#FFFFFF`
- **边框**：无或与背景色一致
- **文字色**：`#2761CB`（蓝色，表示激活）

**半选（Indeterminate）**
- **形状**：方形
- **填充**：蓝色背景
- **背景色**：`#2761CB` (Blue-06)
- **图标**：白色横线 -
- **图标色**：`#FFFFFF`
- **用途**：表示部分子选项被选中（如：树形结构中父节点）
- **文字色**：`#2761CB`

**悬停（Hover）**
- 背景颜色略微变亮
- 或添加背景高亮效果

---

#### 2. 禁用状态

**已选禁用（Checked Disabled）**
- **形状**：方形
- **填充**：灰色背景
- **背景色**：约 `#546789` 或更暗
- **图标**：灰色对勾或更暗的白色对勾
- **图标色**：约 `#8BA8D3` 或类似
- **文字色**：`#546789`（辅助文字色，表示禁用）
- **光标**：not-allowed

**未选禁用（Disabled）**
- **形状**：方形边框
- **填充**：无
- **边框色**：约 `#546789` 或更暗
- **文字色**：`#546789`（辅助文字色）
- **光标**：not-allowed

---

### 设计规范（从图片观察）

| 属性 | 未选中 | 选中 | 半选 | 已选禁用 | 未选禁用 |
|------|--------|------|------|---------|---------||
| **背景色** | 透明 | #2761CB | #2761CB | #546789 | 透明 |
| **边框色** | #546789 | #2761CB | #2761CB | #546789 | #546789 |
| **图标** | 无 | ✓ 白色 | - 白色 | ✓ 灰色 | 无 |
| **文字颜色** | #A6C0CE | #2761CB | #2761CB | #546789 | #546789 |
| **尺寸** | 16px | 16px | 16px | 16px | 16px |
| **圆角** | 2-3px | 2-3px | 2-3px | 2-3px | 2-3px |

---

### 布局规范

- **文字与复选框间距**：约 8px
- **选项之间间距**：约 24-32px（横向排列）
- **垂直间距**：约 16px（纵向排列）

## 三、设计原则

### 1. 清晰的状态区分
- **颜色区分**：选中使用蓝色（#2761CB），未选中使用灰色（#546789）
- **图标区分**：选中显示对勾/圆点，未选中为空
- **禁用状态**：降低颜色饱和度和亮度

### 2. 一致的视觉语言
- 与按钮、其他表单组件保持一致的蓝色主色调
- 与深色主题的层级系统保持一致

### 3. 清晰的交互反馈
- Hover 状态有视觉变化
- 选中状态有明确的颜色变化
- 禁用状态有明确的视觉提示

### 4. 半选状态（Checkbox 特有）
- 用于表示部分选中的状态
- 常用于树形结构、全选场景
- 横线图标区别于对勾

## 四、使用场景

### Radio 单选
- 性别选择（男/女）
- 支付方式选择（支付宝/微信/银行卡）
- 筛选条件（单选）
- 问卷调查（单选题）

### Checkbox 复选框
- 多条件筛选
- 权限设置（多选）
- 兴趣爱好选择
- 问卷调查（多选题）
- 全选/部分选择场景

## 六、与其他组件的关系

**相关组件**：
- **Switch 开关** - 用于即时生效的开关场景
- **Select 下拉选择** - 用于选项很多的场景
- **Button 按钮** - 配合使用提交选择

**选择指南**：
- 选项 ≤5 个，且互斥 → 使用 **Radio**
- 选项 ≤5 个，且可多选 → 使用 **Checkbox**
- 选项 >5 个 → 考虑使用 **Select 下拉选择**
- 即时生效的开关 → 使用 **Switch**

## 七、实现建议（开发参考）

### Radio 实现要点
```tsx
// 伪代码示例
<Radio 
  checked={selected}
  disabled={disabled}
  onChange={handleChange}
>
  选项文字
</Radio>
```

### Checkbox 实现要点
```tsx
// 伪代码示例
<Checkbox 
  checked={checked}
  indeterminate={indeterminate}
  disabled={disabled}
  onChange={handleChange}
>
  选项文字
</Checkbox>
```

### 样式关键点
- 使用 `appearance: none` 移除默认样式
- 使用伪元素 `::before` 或 `::after` 绘制对勾/圆点
- 使用 `:checked` 伪类控制选中状态
- 使用 `:indeterminate` 伪类控制半选状态（Checkbox）
- 使用 `:disabled` 伪类控制禁用状态
- 使用 `transition` 添加平滑过渡动画
