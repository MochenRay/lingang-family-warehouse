# Panel 面板组件

## 来源
SENSORO 设计系统 / 深色模式 / 面板

## 设计理念
面板是承载内容的基础容器，用于将相关内容组织在一起，提供清晰的信息层级和良好的视觉分组。面板组件广泛应用于数据展示、统计、列表、监控等场景。

```tsx
import panelSpecs from 'figma:asset/[从Figma导入的图片ID].png';
```

## 组件总览

面板组件包含 **11 个核心类型**，用于不同场景的内容展示。

| 组件 | 说明 | 使用场景 |
|------|------|---------|
| **基础面板** | 标准容器面板 | 基础内容承载 |
| **范围 Panel** | 统计数据面板 | 数据统计、概览展示 |
| **统计抬头面板** | 带图片预览的统计 | 图片 + 统计数据组合 |
| **区县自检** | 区域检查面板 | 区域数据检查、对比 |
| **自检预警** | 预警列表面板 | 预警信息、异常提示 |
| **树形** | 树形结构面板 | 层级数据展示 |
| **工作列表** | 任务列表面板 | 工作任务、待办事项 |
| **工作列表2** | 带状态的任务列表 | 任务状态管理 |
| **动态人口统计** | 统计列表面板 | 数据统计、排行榜 |
| **对讲记录** | 通信记录面板 | 对讲历史、通话记录 |
| **抓拍视频** | 视频监控面板 | 视频预览、监控回放 |

## 一、基础面板（Panel）

### 设计说明
最基础的面板容器，用于承载各种内容。提供标题、内容区域、边框等基础样式。

### 组件特点
- **标题区域**：显示面板标题和操作按钮
- **内容区域**：承载主要内容
- **边框样式**：清晰的视觉边界
- **可折叠**：支持折叠展开（可选）

---

## 二、基础面板样式规范

### 1. 基础样式

**容器规范**
- **背景色**：`#1F293A`（Neutral-02）
- **边框**：1px solid `#293449`（Neutral-03）
- **圆角**：4px
- **内边距**：16px

### 2. 标题区域

**标题容器**
- **高度**：40px-48px

**标题文字**

- **字重**：Medium（500）

**副标题/描述**（可选）
- **字号**：12px
- **颜色**：`#8194B5`（Neutral-08）
- **位置**：标题下方或右侧

---

### 3. 操作按钮区域

**按钮位置**：标题右侧

**按钮样式**
- **大小**：24px × 24px 或 28px × 28px

**常用操作**

- **展开/折叠**：∧ / ∨ 图标

### 4. 内容区域

**滚动条样式**（见 Scrollbar 组件规范）

### 5. 分隔线

## 三、范围 Panel（统计数据面板）

### 设计说明
用于展示统计数据的面板，通常包含图片、数值、标签等元素，适合数据概览场景。

### 组件特点
- **图片展示**：支持缩略图或图标
- **数值突出**：大字号显示关键数值
- **标签说明**：清晰的标签文字
- **紧凑布局**：有效利用空间

## 二十五、设计原则

### 1. 清晰的信息层级
- **标题突出**：使用大字号和高对比度
- **内容区分**：使用颜色和字号区分主次信息
- **视觉分组**：使用分隔线和间距组织内容

### 2. 一致的视觉语言
- **统一圆角**：4px（容器）、2px（内部元素）
- **统一间距**：16px（主要间距）、8px（次要间距）
- **统一颜色**：使用色彩系统中的标准颜色

### 3. 良好的可读性
- **对比度**：符合 WCAG AA 标准
- **字号**：不小于 12px
- **行高**：1.5-1.8 倍

### 4. 适当的留白
- **内边距**：充足的内边距提升可读性
- **间距**：适当的元素间距避免拥挤
- **呼吸感**：留白让界面更清爽
