# Navigation 导航组件

## 来源
SENSORO 设计系统 / 深色模式 / 导航

## 设计理念
导航组件用于帮助用户在应用中定位和浏览内容，提供清晰的路径指引和操作入口。

## 图片引用
```tsx
import navigationSpecs from 'figma:asset/[从Figma导入的图片ID].png';
```

---

## 组件总览

导航组件包含 **6 个核心组件**，用于不同场景的页面导航。

| 组件 | 说明 | 使用场景 |
|------|------|---------|
| **Anchor** | 锚点定位 | 长页面内容定位、目录导航 |
| **Tabs** | 标签页 | 内容分类切换、视图切换 |
| **Breadcrumb** | 面包屑 | 页面层级导航、路径展示 |
| **Steps** | 步骤条 | 多步骤流程、进度展示 |
| **Menu** | 侧边导航菜单 | 主导航、功能入口 |
| **Tree** | 树形菜单 | 层级结构展示、文件目录 |

---

## 一、Anchor 锚点定位

### 设计说明
用于在长页面中快速定位到指定内容区域，通常配合滚动使用。

### 组件特点
- **固定位置**：通常固定在页面右侧或左侧
- **当前位置指示**：高亮显示当前所在区域
- **点击跳转**：点击锚点快速滚动到目标位置
- **自动更新**：滚动时自动更新当前锚点

---

## 二、Anchor 样式规范

### 1. 基础样式

**容器规范**
- **宽度**：固定宽度（如 120px）或自适应
- **背景色**：透明或 `rgba(31,41,58,0.8)`（半透明背景）
- **位置**：`fixed`，通常在右侧
- **垂直居中**：距离顶部 50%，向上偏移自身高度的 50%

**锚点项**
- **高度**：32px
- **内边距**：8px 16px
- **字号**：14px
- **颜色**：`#8194B5`（Neutral-08，未激活）
- **行高**：22px

---

### 2. 激活状态

**当前锚点**
- **文字颜色**：`#4E86DF`（Blue-07）
- **指示器**：
  - 位置：左侧
  - 宽度：2px
  - 高度：100%（锚点项高度）
  - 颜色：`#4E86DF`（Blue-07）
  - 圆角：1px

**示例**
```
┌────────────┐
│ │ 锚点1    │  ← 未激活
│ │ 锚点2    │
│█│ 锚点3    │  ← 当前激活（蓝色竖线）
│ │ 锚点4    │
└────────────┘
```

---

### 3. Hover 状态

**悬停效果**
- **文字颜色**：`#AEC0DE`（Neutral-10）
- **背景色**：`rgba(78,134,223,0.08)`（Blue-07 8% 透明）
- **光标**：`pointer`

---

### 4. 带标签的锚点

**布局**
```
┌────────────────────┐
│ │ 第一章          │
│ │   1.1 小节      │  ← 缩进显示层级
│█│   1.2 小节      │  ← 当前位置
│ │ 第二章          │
└────────────────────┘
```

**层级缩进**
- 一级：内边距左侧 16px
- 二级：内边距左侧 32px
- 三级：内边距左侧 48px

## 三、Tabs 标签页

### 设计说明
用于在同一页面内切换不同内容视图，是最常用的导航组件之一。

### 组件特点
- **互斥选择**：同一时间只能选中一个标签
- **清晰标识**：选中状态明显区分
- **支持角标**：可显示数字提示
- **支持禁用**：可禁用某些标签

---

## 五、Breadcrumb 面包屑

### 设计说明
显示当前页面在网站层级结构中的位置，帮助用户理解路径并快速返回。

### 组件特点
- **层级展示**：清晰显示页面层级
- **可点击返回**：点击任意层级快速跳转
- **分隔符**：使用斜杠或箭头分隔
- **最后一项**：当前页面不可点击

---

### 1. 基础样式

**容器规范**
- **高度**：32px
- **背景色**：`#0D121B`（Neutral-00）或透明
- **内边距**：0 20px

**面包屑项**
- **字号**：14px
- **字重**：Regular（400）
- **行高**：22px
- **间距**：各项之间 8px

---

### 2. 链接样式

**可点击项（非当前页）**
- **文字颜色**：`#8194B5`（Neutral-08）
- **Hover 颜色**：`#4E86DF`（Blue-07）
- **光标**：`pointer`

**当前页（最后一项）**
- **文字颜色**：`#F6F9FE`（Neutral-11）
- **不可点击**
- **光标**：`default`

---

### 3. 分隔符

**斜杠分隔符**
- **字符**：`/`
- **颜色**：`#8194B5`（Neutral-08）
- **间距**：左右各 8px

**箭头分隔符**
- **字符**：`→` 或 `>`
- **颜色**：`#8194B5`（Neutral-08）
- **间距**：左右各 8px

**示例**
```

↑ 可点击   ↑ 可点击     ↑ 当前页（高亮）
```

---

### 4. 带图标的面包屑

**首页图标**
- **大小**：16px × 16px
- **颜色**：`#8194B5`（Neutral-08）
- **位置**：第一项文字左侧
- **间距**：与文字间距 4px

**示例**
```
🏠 首页 / 用户管理 / 用户列表
```

---

### 5. 溢出处理

**折叠显示**（超过 5 级）
```
首页 / ... / 三级页面 / 四级页面 / 当前页面
       ↑ 折叠中间层级
```

**下拉展开**
- 点击 `...` 显示完整路径
- 使用 Dropdown 组件

## 七、Steps 步骤条

### 设计说明
引导用户完成多步骤流程，清晰展示当前进度和剩余步骤。

### 组件特点
- **进度展示**：明确当前所在步骤
- **状态区分**：完成、进行中、未开始
- **描述信息**：支持标题和描述文字
- **可点击返回**：已完成步骤可点击返回

---

## 八、Steps 样式规范

### 1. 水平步骤条

**容器规范**
- **高度**：自适应（最小 64px）
- **背景色**：透明
- **内边距**：24px 0

**步骤项布局**
- **排列方式**：水平均分
- **对齐方式**：居中对齐

---

### 2. 步骤节点

**圆形节点（默认）**
- **大小**：32px × 32px（圆形）
- **边框**：2px solid
- **圆角**：50%

**状态颜色**

| 状态 | 背景色 | 边框色 | 图标/数字颜色 |
|------|--------|--------|-------------|

| **错误** | `#1F293A`（Neutral-02） | `#E7484F`（Red-07） | `#E7484F` |

**节点内容**
- **已完成**：✓ 对勾图标（白色）
- **进行中**：步骤数字（蓝色）
- **未开始**：步骤数字（灰色）

- **字重**：Regular（400）

## 九、Menu 侧边导航菜单

### 设计说明
提供应用的主要功能入口，通常位于页面左侧，支持多级菜单和折叠展开。

### 组件特点
- **多级嵌套**：支持无限层级
- **折叠展开**：支持菜单项折叠和展开

## 十六、设计原则

### 1. 清晰的视觉层级
- **Tabs**：选中状态明显区分（蓝色下划线）
- **Menu**：激活项突出显示（左侧蓝色竖线 + 浅蓝背景）
- **Steps**：用颜色和图标区分状态

### 2. 一致的交互反馈
- **Hover**：所有可点击项都有 Hover 效果
- **激活**：使用统一的蓝色主题色
- **动画**：平滑的过渡动画（200-300ms）

### 3. 良好的信息架构
- **Breadcrumb**：不超过 5 级，超出折叠
- **Menu**：层级不超过 3 级
- **Tree**：支持无限层级，但建议不超过 5 级

### 4. 响应式设计
- **移动端 Tabs**：支持滑动切换
- **移动端 Menu**：抽屉式侧边栏
- **移动端 Breadcrumb**：只显示当前页和上一级

## 十七、最佳实践

### Tabs 标签页
- ✅ 标签文字简洁（2-6 个字）
- ✅ 标签数量 2-7 个（超过考虑下拉菜单）
- ✅ 使用图标 + 文字增强识别
- ❌ 避免标签文字过长导致换行

### Breadcrumb 面包屑
- ✅ 最后一项为当前页面，不可点击
- ✅ 使用斜杠 `/` 或箭头 `>` 分隔
- ✅ 超过 5 级折叠中间层级
- ❌ 避免面包屑过长影响布局

### Steps 步骤条
- ✅ 步骤数量 3-7 个
- ✅ 已完成步骤可点击返回
- ✅ 使用图标增强识别（✓ ✕）
- ❌ 避免步骤文字过长

### Menu 侧边导航
- ✅ 层级不超过 3 级
- ✅ 使用图标增强识别
- ✅ 分组使用分隔线或标题
- ❌ 避免菜单项过多（超过 15 项考虑分组）

### Tree 树形菜单
- ✅ 提供搜索功能（节点较多时）
- ✅ 支持展开/折叠全部
- ✅ 高亮搜索结果
- ❌ 避免默认展开所有节点（影响性能）
