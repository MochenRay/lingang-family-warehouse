# 导航组件（Navigation）

## 来源
SENSORO 设计系统 / 深色模式 / 导航

## 设计理念
导航组件用于帮助用户在应用中定位和浏览内容，提供清晰的路径指引和操作入口。

## 一、组件分类

### 1. 页面内导航

#### Anchor 锚点定位
- **用途**：长页面内容定位、目录导航
- **特点**：固定位置、当前位置指示、点击跳转、自动更新
- **位置**：通常固定在页面右侧

**核心特性**：
- 高亮显示当前所在区域（蓝色竖线指示器）
- 点击锚点快速滚动到目标位置
- 滚动时自动更新当前锚点
- 支持多级层级（缩进显示）

---

#### Tabs 标签页
- **用途**：内容分类切换、视图切换
- **特点**：互斥选择、清晰标识、支持角标、支持禁用
- **类型**：线条型、卡片型

**核心特性**：
- 同一时间只能选中一个标签
- 蓝色下划线指示选中状态（线条型）
- 滑动动画（300ms）
- 支持数字角标提示（如：领取中心 ①）

---

### 2. 页面间导航

#### Breadcrumb 面包屑
- **用途**：页面层级导航、路径展示
- **特点**：层级展示、可点击返回、分隔符、最后一项不可点击
- **位置**：通常在页面顶部

**核心特性**：
- 清晰显示页面在网站层级结构中的位置
- 点击任意层级快速跳转
- 使用斜杠 `/` 或箭头 `>` 分隔
- 超过 5 级自动折叠中间层级

**示例**：
```
推理分析 / 巡航管理 / 城市巡航
```

---

#### Menu 侧边导航菜单
- **用途**：主导航、功能入口
- **特点**：多级嵌套、折叠展开、图标支持、激活状态
- **位置**：页面左侧

**核心特性**：
- 支持无限层级嵌套（建议不超过 3 级）
- 左侧蓝色竖线指示选中项
- 选中项浅蓝色背景高亮
- 展开/折叠动画（300ms）

---

### 3. 流程导航

#### Steps 步骤条
- **用途**：多步骤流程、进度展示
- **特点**：进度展示、状态区分、描述信息、可点击返回
- **类型**：水平、垂直

**核心特性**：
- 4 种状态：已完成、进行中、未开始、错误
- 圆形节点 + 连接线
- 已完成显示 ✓ 图标
- 支持标题和描述文字

**状态颜色**：
- 已完成：蓝色（`#4E86DF`）
- 进行中：蓝色边框
- 未开始：灰色（`#293449`）
- 错误：红色（`#E7484F`）

---

### 4. 结构导航

#### Tree 树形菜单
- **用途**：层级结构展示、文件目录
- **特点**：层级展示、展开折叠、节点选择、图标支持
- **应用**：文件管理、组织架构、分类管理

**核心特性**：
- 清晰展示父子关系（缩进 + 连接线）
- 支持单选或多选（复选框模式）
- 文件夹和文件图标区分
- 搜索高亮功能

## 二、通用设计规范

### 颜色系统（所有导航组件）

| 状态/场景 | 主要颜色 | 使用场景 |
|---------|---------|---------|
| **激活/选中** | `#4E86DF`（Blue-07） | Anchor、Tabs、Menu、Tree 选中项 |
| **默认/未选中** | `#AEC0DE`（Neutral-10） | 默认文字颜色 |
| **辅助/次要** | `#8194B5`（Neutral-08） | Breadcrumb 链接、未激活项 |
| **当前页/高亮** | `#F6F9FE`（Neutral-11） | Breadcrumb 当前页、Tabs 选中文字 |
| **禁用** | `#546789`（Neutral-06） | 禁用状态 |
| **背景（选中）** | `rgba(78,134,223,0.08)`（Blue-07 8%） | Menu、Tree 选中背景 |
| **完成状态** | `#4E86DF`（Blue-07） | Steps 已完成 |
| **错误状态** | `#E7484F`（Red-07） | Steps 错误 |

## 三、交互规范

### 点击交互

| 组件 | Click 效果 |
|------|-----------|
| **Anchor** | 平滑滚动到目标区域（800ms） |
| **Tabs** | 切换标签，指示器滑动动画（300ms） |
| **Breadcrumb** | 跳转到对应层级页面 |
| **Steps（已完成）** | 返回到该步骤 |
| **Menu** | 激活菜单项，展开/折叠子菜单 |
| **Tree** | 展开/折叠节点，选中节点 |

---

### Hover 交互

| 组件 | Hover 效果 |
|------|-----------|
| **Anchor** | 文字颜色变亮，浅蓝背景 |
| **Tabs** | 文字颜色变亮，浅灰背景 |
| **Breadcrumb** | 链接变蓝色 |
| **Menu** | 浅灰背景，文字颜色变亮 |
| **Tree** | 浅灰背景 |

---

### 动画效果

| 组件 | 动画 | 持续时间 |
|------|------|---------|
| **Anchor 滚动** | 平滑滚动 | 800ms |
| **Tabs 指示器** | 滑动过渡 | 300ms |
| **Menu 展开** | 高度展开 + 图标旋转 | 300ms |
| **Tree 展开** | 高度展开 + 淡入 | 300ms |
| **Steps 颜色** | 颜色变化 | 200ms |

**缓动函数**：`ease-in-out`

## 五、设计原则

### 1. 清晰的视觉层级
- **激活状态突出**：使用蓝色主题色 + 指示器
- **层级关系明确**：使用缩进 + 连接线
- **当前位置清晰**：高亮显示当前所在位置

### 2. 一致的交互反馈
- **Hover 效果**：所有可点击项都有明显的 Hover 反馈
- **激活状态**：统一使用蓝色（`#4E86DF`）
- **动画过渡**：平滑的过渡动画（200-300ms）

### 3. 合理的信息架构
- **Breadcrumb**：不超过 5 级，超出折叠
- **Menu**：层级不超过 3 级
- **Tree**：支持无限层级，但建议不超过 5 级
- **Tabs**：标签数量 2-7 个，超过考虑下拉菜单

### 4. 良好的可访问性
- **键盘支持**：支持 Tab、Arrow、Enter/Space 操作
- **ARIA 属性**：为所有组件提供语义化标签
- **屏幕阅读器**：提供清晰的文字标签

## 六、最佳实践

### Anchor 锚点定位
- ✅ 锚点数量 3-10 个
- ✅ 锚点文字简洁（2-8 个字）
- ✅ 固定在页面右侧或左侧
- ❌ 避免锚点过多（超过 10 个考虑分组）

### Tabs 标签页
- ✅ 标签文字简洁（2-6 个字）
- ✅ 标签数量 2-7 个（超过考虑下拉菜单）
- ✅ 使用图标 + 文字增强识别
- ❌ 避免标签文字过长导致换行

### Breadcrumb 面包屑
- ✅ 最后一项为当前页面，不可点击
- ✅ 使用斜杠 `/` 或箭头 `>` 分隔
- ✅ 超过 5 级折叠中间层级
- ❌ 避免面包屑过长影响布局

### Steps 步骤条
- ✅ 步骤数量 3-7 个
- ✅ 已完成步骤可点击返回
- ✅ 使用图标增强识别（✓ 已完成，✕ 错误）
- ❌ 避免步骤文字过长

### Menu 侧边导航
- ✅ 层级不超过 3 级
- ✅ 使用图标增强识别
- ✅ 分组使用分隔线或标题
- ❌ 避免菜单项过多（超过 15 项考虑分组）

### Tree 树形菜单
- ✅ 提供搜索功能（节点较多时）
- ✅ 支持展开/折叠全部
- ✅ 高亮搜索结果
- ❌ 避免默认展开所有节点（影响性能）

## 七、组件选择决策树

### 页面内导航

```
内容是否在同一个页面？
  ├─ 是 ↓
  │  
  │  内容是否需要分类切换？
  │    ├─ 是 → Tabs（标签页）
  │    └─ 否 ↓
  │  
  │  是否需要快速定位到某个区域？
  │    ├─ 是 → Anchor（锚点定位）
  │    └─ 否 → 不需要导航组件
  │  
  └─ 否 → 页面间导航 ↓
```

---

### 页面间导航

```
是否需要展示页面层级路径？
  ├─ 是 → Breadcrumb（面包屑）
  └─ 否 ↓

是否需要主导航菜单？
  ├─ 是 ↓
  │  
  │  内容是否有层级结构？
  │    ├─ 是 → Menu（侧边导航）+ Tree（树形菜单）
  │    └─ 否 → Menu（侧边导航）
  │  
  └─ 否 ↓

是否是多步骤流程？
  ├─ 是 → Steps（步骤条）
  └─ 否 → 使用 Button 或 Link
```

## 八、响应式设计

### 移动端适配

| 组件 | 移动端调整 |
|------|-----------| 
| **Anchor** | 改为顶部横向滚动或隐藏 |
| **Tabs** | 支持左右滑动切换，标签宽度自适应 |
| **Breadcrumb** | 只显示当前页和上一级，其他折叠 |

## 十、常见问题

### 1. Tabs 和 Segmented 有什么区别？
- **Tabs**：页面级别的内容切换，通常更大，位于页面顶部
- **Segmented**：组件级别的选项切换，更紧凑，可内嵌在表单中

### 2. Breadcrumb 应该放在哪里？
- 通常放在页面顶部，标题下方或上方
- 与页面标题保持 16px 间距

### 3. Menu 最多支持几级？
- 建议不超过 3 级
- 超过 3 级考虑使用 Tree 或调整信息架构

### 4. Steps 步骤条应该用水平还是垂直？
- 桌面端：水平（步骤 ≤ 5 个）
- 移动端或步骤较多：垂直
- 步骤包含详细描述：垂直

### 5. Tree 如何优化性能？
- 虚拟滚动（节点 > 1000 个）
- 懒加载子节点
- 默认只展开前 2 级
- 提供搜索功能
