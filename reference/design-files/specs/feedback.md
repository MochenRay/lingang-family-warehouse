# Feedback 反馈组件

## 来源
SENSORO 设计系统 / 深色模式 / 反馈

## 设计理念
反馈组件用于向用户传达操作结果、系统状态或需要用户确认的信息，是产品和用户进行交互的重要方式。

## 图片引用
```tsx
import feedbackSpecs from 'figma:asset/[从Figma导入的图片ID].png';
```

---

## 组件总览

反馈组件包含 **5 个核心组件**，用于不同场景的用户反馈。

| 组件 | 说明 | 使用场景 |
|------|------|---------|
| **Modal** | 模态框 | 重要信息展示、表单录入、确认操作 |
| **Confirm** | 二次确认对话框 | 删除、重要操作确认 |
| **Alert** | 警告条 | 页面级别的提示信息 |
| **Message** | 消息提醒 | 操作反馈、轻量提示 |
| **Notification** | 通知提醒框 | 系统通知、复杂消息 |

---

## 一、Modal 模态框

### 设计说明
在当前页面上层打开浮层，承载相关操作或信息展示。

### 组件特点
- **页面遮罩**：半透明黑色背景
- **居中展示**：内容居中显示
- **标题+内容+操作**：清晰的信息层级
- **关闭方式**：点击遮罩、ESC 键、关闭按钮

---

## 三、Confirm 二次确认对话框

### 设计说明
用于需要用户二次确认的重要操作，如删除、提交等。

### 组件特点
- **图标提示**：视觉化表达操作类型
- **清晰标题**：明确说明操作
- **详细描述**：解释操作后果
- **双按钮**：取消 + 确定

## 五、Alert 警告条

## 七、Message 消息提醒

### 设计说明
轻量级的全局提示，主要用于操作反馈，自动消失。

### 组件特点
- **轻量级**：简洁的图标 + 文字
- **自动消失**：默认 3 秒后消失
- **顶部居中**：屏幕顶部居中显示
- **多条堆叠**：支持多条消息依次显示

---

**容器规范**

  ```css

  ```
- **内边距**：12px 16px

### 2. 内容布局

**图标**
- **大小**：16px × 16px
- **位置**：左侧
- **间距**：与文字间距 8px

**文字**
- **字号**：14px
- **字重**：Regular（400）
- **颜色**：`#AEC0DE`（Neutral-10）
- **行高**：22px
- **最大行数**：2 行（超出省略）

---

### 3. 类型样式

| 类型 | 图标 | 图标颜色 | 使用场景 |
|------|------|---------|---------|
| **成功** | ✓ | `#0DA5CA`（Green-06） | 操作成功 |
| **信息** | ℹ️ | `#4E86DF`（Blue-07） | 一般提示 |
| **警告** | ⚠️ | `#FB923C`（Orange-07） | 警告信息 |
| **错误** | ✕ | `#E7484F`（Red-07） | 操作失败 |
| **加载** | ⟳ | `#4E86DF`（Blue-07） | 加载中 |

---

### 4. 动画效果

**显示动画**
- **类型**：淡入 + 向下移动
- **持续时间**：300ms
- **缓动函数**：ease-out
- **移动距离**：-20px → 0px

**消失动画**
- **类型**：淡出 + 向上移动
- **持续时间**：300ms
- **缓动函数**：ease-in
- **移动距离**：0px → -20px

**堆叠动画**
- 新消息插入时，旧消息向下移动
- 消息消失时，下方消息向上补位

---

### 5. 时长配置

| 类型 | 默认显示时长 |
|------|------------|
| **成功** | 3 秒 |
| **信息** | 3 秒 |
| **警告** | 4 秒 |
| **错误** | 5 秒 |
| **加载** | 手动关闭 |

**自定义时长**：支持设置 0（手动关闭）或任意秒数

## 十四、设计原则

### 1. 清晰的信息层级
- **标题 > 描述 > 操作**
- 使用字号、颜色、间距区分层级
- 关键信息突出显示

### 2. 一致的视觉语言
- **颜色系统**：蓝（信息）、绿（成功）、橙（警告）、红（错误）
- **图标系统**：统一的图标风格
- **圆角系统**：4px（小组件）、8px（大组件）

### 3. 合理的交互反馈
- **及时性**：操作后立即反馈
- **适度性**：根据重要性选择合适的组件
- **非侵入性**：轻量提示不打断用户

### 4. 良好的可访问性
- **ARIA 属性**：为所有组件提供语义化标签
- **键盘支持**：Modal 和 Confirm 支持键盘操作
- **对比度**：符合 WCAG AA 标准

## 十五、最佳实践

### Modal 模态框

## 十七、实现代码（React + Tailwind）

### Message 消息提醒

```tsx
import React from 'react';
import { createPortal } from 'react-dom';

type MessageType = 'success' | 'info' | 'warning' | 'error';

interface MessageProps {
  type: MessageType;
  content: string;
  duration?: number;
  onClose?: () => void;
}

const MessageIcon: React.FC<{ type: MessageType }> = ({ type }) => {
  const icons = {
    success: '✓',
    info: 'ℹ️',
    warning: '⚠️',
    error: '✕',
  };

  const colors = {
    success: 'text-[#0DA5CA]',
    info: 'text-[#4E86DF]',
    warning: 'text-[#FB923C]',
    error: 'text-[#E7484F]',
  };

  return (
    <span className={`text-base ${colors[type]}`}>
      {icons[type]}
    </span>
  );
};

export const Message: React.FC<MessageProps> = ({
  type,
  content,
  duration = 3000,
  onClose,
}) => {
  const [visible, setVisible] = React.useState(false);

  React.useEffect(() => {
    // 显示动画
    setVisible(true);

    // 自动关闭
    if (duration > 0) {
      const timer = setTimeout(() => {
        setVisible(false);
        setTimeout(() => {
          onClose?.();
        }, 300);
      }, duration);

      return () => clearTimeout(timer);
    }
  }, [duration, onClose]);

  return createPortal(
    <div
      className={`
        fixed top-6 left-1/2 -translate-x-1/2 z-[2000]
        transition-all duration-300
        ${visible ? 'opacity-100 translate-y-0' : 'opacity-0 -translate-y-5'}
      `}
    >
      <div className="bg-[#1F293A] rounded px-4 py-3 shadow-lg flex items-center gap-2 min-w-[200px] max-w-[400px]">
        <MessageIcon type={type} />
        <span className="text-sm text-[#AEC0DE]">{content}</span>
      </div>
    </div>,
    document.body
  );
};

// 使用示例
export const showMessage = (type: MessageType, content: string, duration?: number) => {
  // 实际使用时需要配合状态管理或消息队列
  console.log(`${type}: ${content}`);
};

// 组件使用示例
export default function Example() {
  const [messages, setMessages] = React.useState<Array<{id: number; type: MessageType; content: string}>>([]);

  const addMessage = (type: MessageType, content: string) => {
    const id = Date.now();
    setMessages(prev => [...prev, { id, type, content }]);
  };

  const removeMessage = (id: number) => {
    setMessages(prev => prev.filter(msg => msg.id !== id));
  };

  return (
    <div className="p-8 space-y-4">
      <button
        onClick={() => addMessage('success', '操作成功！')}
        className="px-4 py-2 bg-[#2761CB] text-white rounded"
      >
        显示成功消息
      </button>
      <button
        onClick={() => addMessage('error', '操作失败，请重试')}
        className="px-4 py-2 bg-[#E7484F] text-white rounded"
      >
        显示错误消息
      </button>

      {messages.map(msg => (
        <Message
          key={msg.id}
          type={msg.type}
          content={msg.content}
          onClose={() => removeMessage(msg.id)}
        />
      ))}
    </div>
  );
}
```
