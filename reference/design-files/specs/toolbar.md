# Toolbar 工具栏组件

## 来源
SENSORO 设计系统 / 深色模式 / 工具栏

## 设计理念
提供快捷便捷工作场景，便捷的方式相比深入到达菜单最终的任务，要比点击之后到达更加高效。工具栏通常用于地图应用、编辑器、设计工具等需要快速操作的场景。


## 组件总览

工具栏组件包含 **4 个核心组件**，用于不同场景的工具操作。

| 组件 | 说明 | 使用场景 |
|------|------|---------|
| **定制栏** | 垂直工具栏 | 主要操作入口、常用工具快捷方式 |
| **设置面板栏** | 设置面板 | 参数配置、选项设置 |
| **地图工具栏** | 地图操作工具 | 地图缩放、定位、测量等 |
| **地图图层** | 图层选择器 | 地图样式、图层管理 |

---

## 一、定制栏（垂直工具栏）

### 设计说明
提供主要操作入口的垂直工具栏，通常固定在页面左侧或右侧，包含常用工具的快捷图标按钮。

### 组件特点
- **固定位置**：通常固定在页面左侧或右侧
- **图标按钮**：清晰的图标表达工具功能
- **激活状态**：高亮显示当前激活的工具
- **Tooltip 提示**：Hover 显示工具名称

---

## 二、定制栏样式规范

### 1. 基础样式

**容器规范**
- **宽度**：56px（固定）
- **背景色**：`#161D2A`（Neutral-01）或 `rgba(22,29,42,0.9)`（半透明）

- **图标大小**：24px × 24px

## 五、地图工具栏

### 设计说明
专为地图应用设计的工具栏，提供地图操作相关的工具，如缩放、定位、测量、标注等。

### 组件特点
- **固定位置**：通常在地图左下角或右下角
- **紧凑布局**：工具按钮紧密排列
- **快速操作**：一键触达常用功能
- **状态反馈**：清晰的激活和禁用状态

---

- **📐**：面积测量

**标注工具**
- **📌**：标记点
- **✏️**：绘制

## 十、使用场景

### 定制栏（垂直工具栏）
- ✅ 地图应用主操作工具（缩放、定位、测量）
- ✅ 编辑器工具栏（文本、形状、画笔）
- ✅ 设计工具侧边栏（选择、移动、旋转）
- ✅ 视频编辑器工具（剪切、复制、删除）

### 设置面板栏
- ✅ 地图设置（显示标签、显示网格、透明度）
- ✅ 图层样式配置（颜色、线宽、填充）
- ✅ 视频播放器设置（音量、速度、字幕）
- ✅ 编辑器偏好设置（主题、字号、自动保存）

### 地图工具栏
- ✅ 地图缩放（放大、缩小、复位）
- ✅ 地图定位（当前位置、中心定位）
- ✅ 地图测量（距离、面积、角度）
- ✅ 地图标注（标记、绘制、清除）

### 地图图层
- ✅ 地图样式切换（默认、卫星、地形）
- ✅ 图层显示控制（行政区划、热力图、道路）
- ✅ 图层透明度调整
- ✅ 多图层叠加显示

## 十二、设计原则

### 1. 快速访问
- **常用工具优先**：最常用的工具放在顶部或左侧
- **一键触达**：主要操作一次点击即可完成
- **快捷键支持**：提供键盘快捷键

### 2. 清晰的状态反馈
- **激活状态明显**：使用蓝色主题色高亮
- **Hover 反馈**：所有可点击项都有 Hover 效果
- **禁用状态清晰**：灰色显示，光标 not-allowed

### 3. 一致的视觉语言
- **统一的圆角**：8px（容器）、4px（按钮）
- **统一的间距**：8px（主要间距）、4px（紧凑间距）
- **统一的颜色**：蓝色（`#4E86DF`）用于激活状态

### 4. 良好的可访问性
- **Tooltip 提示**：Hover 显示工具名称
- **键盘支持**：支持 Tab、Enter、Space 操作
- **对比度**：符合 WCAG AA 标准

## 十五、实现代码（React + Tailwind）

### 定制栏（垂直工具栏）

```tsx
import React from 'react';

interface ToolbarItem {
  id: string;
  icon: React.ReactNode;
  label: string;
  shortcut?: string;
}

interface VerticalToolbarProps {
  items: ToolbarItem[];
  activeId?: string;
  onItemClick?: (id: string) => void;
}

export const VerticalToolbar: React.FC<VerticalToolbarProps> = ({
  items,
  activeId,
  onItemClick,
}) => {
  const [hoveredId, setHoveredId] = React.useState<string | null>(null);

  return (
    <div className="w-14 bg-[#161D2A] rounded-lg p-2 shadow-lg">
      <div className="space-y-2">
        {items.map((item, index) => (
          <React.Fragment key={item.id}>
            {index > 0 && index % 3 === 0 && (
              <div className="h-px bg-[#293449] my-2" />
            )}
            <div className="relative">
              <button
                className={`
                  w-10 h-10 rounded flex items-center justify-center
                  transition-all duration-150
                  ${
                    activeId === item.id
                      ? 'bg-[rgba(78,134,223,0.2)] text-[#4E86DF]'
                      : hoveredId === item.id
                      ? 'bg-[rgba(78,134,223,0.12)] text-[#AEC0DE]'
                      : 'text-[#8194B5]'
                  }
                `}
                onClick={() => onItemClick?.(item.id)}
                onMouseEnter={() => setHoveredId(item.id)}
                onMouseLeave={() => setHoveredId(null)}
                aria-label={item.label}
                aria-pressed={activeId === item.id}
                title={`${item.label}${item.shortcut ? ` (${item.shortcut})` : ''}`}
              >
                {item.icon}
              </button>
              
              {/* Tooltip */}
              {hoveredId === item.id && (
                <div className="absolute left-full ml-2 top-1/2 -translate-y-1/2 z-50">
                  <div className="bg-[#314059] text-[#F6F9FE] text-xs px-2 py-1 rounded whitespace-nowrap">
                    {item.label}
                    {item.shortcut && (
                      <span className="ml-2 text-[#8194B5]">{item.shortcut}</span>
                    )}
                  </div>
                </div>
              )}
            </div>
          </React.Fragment>
        ))}
      </div>
    </div>
  );
};

// 使用示例
export default function Example() {
  const [activeTool, setActiveTool] = React.useState('select');

  const tools: ToolbarItem[] = [
    { id: 'select', icon: '↖️', label: '选择工具', shortcut: 'V' },
    { id: 'move', icon: '✋', label: '移动工具', shortcut: 'M' },
    { id: 'zoom', icon: '🔍', label: '缩放工具', shortcut: 'Z' },
    { id: 'measure', icon: '📏', label: '测量工具', shortcut: 'R' },
    { id: 'marker', icon: '📍', label: '标注工具', shortcut: 'P' },
    { id: 'draw', icon: '✏️', label: '绘制工具', shortcut: 'D' },
  ];

  return (
    <div className="p-8 bg-[#0D121B] min-h-screen">
      <VerticalToolbar
        items={tools}
        activeId={activeTool}
        onItemClick={setActiveTool}
      />
    </div>
  );
}
```
