# 元素卡片层级（中性色系统）

## 来源
SENSORO 设计系统 / 深色模式 / 元素卡片层级

## 设计理念
界面内的各个元素是用户获取信息的途径，规范地设置界面内元素的层级，让它们呈现出不同的先后秩序，是我们提升产品体验的关键。所有的透明度参数为用户界面中的分类与背景构建，一般一个层次一般是 4% 递增，这样能让设计更加简单易用。

## 一、背景色基准色

### 主背景色（0阶）
- **色值**：`#0D121B`
- **HSL**：H219°, S35%, L8%
- **用途**：页面主背景色、深色主题底色、最深层级
- **命名**：Neutral-00（中性色-00）

### 配方说明
所有的中性色都基于此背景色，通过混合不同比例的白色（#FFF）和蓝色主题色（#2B6DE5）生成。

**混合公式**：
```
最终色值 = #0D121B + #FFF (X%) + #2B6DE5 (Y%)
```

## 九、设计原则

### 1. 递进式层级
- 每个卡片层级递增 4%（#FFF 和 #2B6DE5 各 4%）
- 文字层级根据可读性需求调整
- 确保相邻层级有明显区分

### 2. 统一的色彩基础
- 所有中性色基于 #0D121B 背景色
- 通过混合白色和蓝色主题色生成
- 保持整体色调的一致性

### 3. 可访问性
- 标题文字（#F6F9FE）与背景（#0D121B）对比度：13.5:1 ✅
- 主要文字（#AEC0DE）与背景（#0D121B）对比度：9.2:1 ✅
- 次要文字（#8194B5）与背景（#0D121B）对比度：5.8:1 ✅
- 辅助文字（#546789）与背景（#0D121B）对比度：3.5:1 ⚠️（仅用于辅助信息）

### 4. 灵活扩展
- 预留了 05、07、09 层级编号
- 可根据需要添加中间层级
- 保持命名规范的一致性

## 十、实现代码（CSS/Tailwind）

### CSS 变量定义

```css
:root {
  /* 背景色 */
  --neutral-00: #0D121B; /* 页面背景 */
  
  /* 卡片层级 */
  --neutral-01: #161D2A; /* 1阶卡片 */
  --neutral-02: #1F293A; /* 2阶卡片 */
  --neutral-03: #293449; /* 3阶卡片 */
  --neutral-04: #314059; /* 4阶卡片 */
  
  /* 文字层级 */
  --neutral-06: #546789; /* 辅助文字 */
  --neutral-08: #8194B5; /* 次要文字 */
  --neutral-10: #AEC0DE; /* 主要文字 */
  --neutral-11: #F6F9FE; /* 标题文字 */
}
```

### Tailwind 配置

```js
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        neutral: {
          0: '#0D121B',   // 页面背景
          1: '#161D2A',   // 1阶卡片
          2: '#1F293A',   // 2阶卡片
          3: '#293449',   // 3阶卡片
          4: '#314059',   // 4阶卡片
          6: '#546789',   // 辅助文字
          8: '#8194B5',   // 次要文字
          10: '#AEC0DE',  // 主要文字
          11: '#F6F9FE',  // 标题文字
        },
      },
    },
  },
};
```

### 使用示例

```tsx
// 卡片组件
<div className="bg-neutral-2 border border-neutral-3">
  <h2 className="text-neutral-11">标题</h2>
  <p className="text-neutral-10">正文内容</p>
  <span className="text-neutral-8">次要信息</span>
</div>

// Hover 状态
<div className="bg-neutral-2 hover:bg-neutral-3">
  卡片内容
</div>

// 选中状态
<div className="bg-neutral-4 border-2 border-blue-6">
  选中的卡片
</div>
```
