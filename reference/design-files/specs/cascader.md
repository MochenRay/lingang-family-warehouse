# Cascader 级联选择器

## 来源
SENSCIO 设计系统 / 深色模式

## 设计理念
级联选择器用于在多级分类中逐级选择数据，常用于省市区选择、组织架构选择等层级结构数据。

## 一、级联选择器（Cascader）

### 设计说明
用于在具有层级关系的数据中进行选择，通过逐级展开的方式选择最终选项。

### 组件特点
- **层级结构**：支持多级数据展开（通常 2-4 级）
- **逐级选择**：选择上级后展开下级选项
- **路径显示**：显示完整的选择路径（如：青海省/西宁市/城西区）
- **深色主题**：使用深色背景和蓝色高亮

---

## 二、状态设计

### 1. Default（默认状态）

**输入框**
- **背景色**：深色背景（约 `#1F293A` 2阶卡片色）
- **文字色**：占位符 `#546789`（辅助文字）
- **占位符**："请选择" 或 "选择省/市/区"
- **右侧图标**：下拉箭头 ▼（灰色）
- **圆角**：约 4-6px
- **内边距**：约 8-12px
- **高度**：约 36-40px

---

### 2. Hover（悬停状态）

**输入框**
- **背景色**：略亮的背景（约 `#263449` 3阶卡片色）
- **边框**：可能有轻微的高亮边框
- **其他**：与 Default 一致

---

### 3. Click（点击展开）

**输入框**
- **背景色**：深色背景
- **边框色**：蓝色边框（`#2761CB`）表示激活
- **下拉箭头**：旋转 180° 指向上方（可选）

**级联面板**
- **背景色**：深色背景（约 `#263449` 3阶卡片色）
- **阴影**：明显的阴影或边框，与页面背景区分
- **圆角**：约 4-6px
- **内边距**：约 8-12px
- **最大高度**：显示 5-8 个选项，超出滚动

**面板布局（从图中示例）**

```
┌──────────────────────────────────────────────┐
│ 青海省/西宁市/城西区                          │  ← 输入框（显示选中路径）
└──────────────────────────────────────────────┘
     ▼
┌──────────────────────────────────────────────┐
│  省份列          城市列          区县列      │
├───────────┬───────────┬──────────────────────┤
│ 北京市   >│ 西宁市   >│ 城区              > │
│ 天津市   >│ 南京市   >│ 城西区            > │
│ 河北省   >│ 海北...  >│ 城中区  👆        > │  ← Hover状态
│ 山西省   >│ 黄南...  >│ 湟中区            > │
│ 青海省 ✓ >│ 海南...  >│ 大通回族土族...   > │
│ 辽宁省   >│ 果洛...  >│ 湟源县            > │
└───────────┴───────────┴──────────────────────┘
```

**面板结构**
- **多列展示**：每一级一列（从图中看是 3 列）
- **垂直滚动**：每列独立滚动
- **列宽**：自适应或固定宽度（约 120-160px）
- **列间距**：列之间有分隔线或留白

---

### 4. 选项状态

#### Normal（普通选项）

**未选中的可展开项**
- **背景色**：透明
- **文字色**：`#A6C0CE`（主要文字）
- **右侧图标**：右箭头 ">" （灰色）
- **文字对齐**：左对齐
- **内边距**：约 8-12px
- **高度**：约 32-36px

**示例**：北京市、天津市、河北省等

---

#### Hover（悬停状态）

**鼠标悬停的选项**
- **背景色**：`#340569`（4阶卡片色）或略亮的背景
- **文字色**：`#F6F9FE`（标题文字，更亮）
- **右侧图标**：右箭头（可能变亮）
- **光标**：手型指针（从图中可见）

**示例**：图中"城中区"处于 Hover 状态

---

#### Selected（选中状态）

**当前选中的选项**
- **背景色**：可能略有高亮（不如 Hover 明显）
- **文字色**：`#2761CB`（蓝色）或 `#F6F9FE`
- **右侧图标**：右箭头 ">"（蓝色）
- **左侧标识**：可能有蓝色竖线或对勾 "✓"

**示例**：图中"青海省"被选中

**选中路径高亮**
- 第一列：青海省（选中）
- 第二列：西宁市（选中）
- 第三列：城西区（选中，最终选项）

---

#### Disabled（禁用选项）

**不可选择的选项**
- **背景色**：透明
- **文字色**：`#546789`（辅助文字，灰色）
- **右侧图标**：右箭头（灰色且暗淡）
- **光标**：not-allowed

---

#### Leaf（叶子节点/最终选项）

**没有下级的最终选项**
- **背景色**：透明
- **文字色**：`#A6C0CE`
- **右侧图标**：无箭头，或对勾 "✓"（如果是选中项）
- **点击后**：选择完成，面板关闭

**示例**：城区、城西区、湟源县（第三列的选项）

---

### 5. Finish（选择完成）

**输入框**
- **背景色**：恢复默认深色
- **显示内容**：显示完整的选择路径
  - **格式**："青海省/西宁市/城西区"
  - **分隔符**："/" 或 " > "
- **文字色**：`#A6C0CE`（主要文字）
- **级联面板**：关闭

---

### 6. Disable（禁用状态）

**输入框**
- **背景色**：更暗的背景（约 `#1810DA` 1阶卡片）
- **文字色**：`#546789`（辅助文字）
- **光标**：not-allowed
- **下拉箭头**：灰色且暗淡
- **无法点击展开**

## 四、交互说明

### 基本交互流程

1. **点击输入框** → 展开级联面板，显示第一级选项
2. **选择第一级** → 高亮选中项，右侧展开第二级选项
3. **选择第二级** → 高亮选中项，右侧展开第三级选项
4. **选择第三级（叶子节点）** → 选择完成，面板关闭，输入框显示完整路径

### 悬停交互

- **鼠标悬停**：选项背景变亮，文字变白
- **移出**：恢复默认状态

### 键盘支持

- **上下键**：在当前列中上下移动
- **左右键**：在列之间左右切换
- **回车键**：选择当前高亮项
- **ESC 键**：关闭面板

### 路径显示

**输入框中的路径**
- **格式**：省份/城市/区县
- **分隔符**："/" 或 " > "
- **溢出**：文字过长时显示省略号 "..."

**示例**
```
青海省/西宁市/城西区
北京市/东城区
```

## 五、使用场景

### 典型应用

1. **地址选择**：省/市/区（最常见）
2. **组织架构**：公司/部门/小组
3. **商品分类**：一级类目/二级类目/三级类目
4. **文件路径**：文件夹/子文件夹/文件
5. **权限设置**：模块/功能/操作

### 何时使用 Cascader

| 场景 | 使用 Cascader | 使用其他组件 |
|------|--------------|-------------|
| **层级 ≥ 3** | ✅ 推荐 | ❌ 不推荐 Select |
| **选项很多** | ✅ 推荐 | ❌ 不推荐 Radio/Checkbox |
| **层级关系明确** | ✅ 推荐 | ❌ 不推荐平铺选择 |
| **需要路径显示** | ✅ 推荐 | - |

## 六、设计原则

### 1. 清晰的层级关系

- **列式布局**：每一级一列，层级一目了然
- **右箭头指示**：有下级的选项显示 ">"
- **路径高亮**：选中路径上的所有节点高亮

### 2. 即时反馈

- **Hover 高亮**：鼠标悬停立即显示反馈
- **选中高亮**：选中项用蓝色标识
- **展开下级**：点击后立即展开下级选项

### 3. 一致的颜色语言

- **主色**：`#2761CB`（Blue-06）用于选中、激活
- **背景层级**：使用元素卡片层级系统
- **Hover 状态**：`#340569`（4阶卡片色）

### 4. 高效的交互

- **键盘导航**：支持键盘操作
- **搜索功能**：支持搜索过滤（可选）
- **快捷选择**：支持直接定位到某一级（可选）

## 七、变体和扩展

### 1. 单列级联（Mobile）

**移动端适配**
- **布局**：单列显示，选中后切换到下一级
- **返回按钮**：顶部有返回上一级的按钮
- **面包屑**：顶部显示当前路径

### 2. 搜索级联

**支持搜索**
- **搜索框**：面板顶部有搜索输入框
- **搜索结果**：显示匹配的所有路径
- **高亮匹配**：匹配的文字高亮显示

### 3. 多选级联

**支持多选**
- **复选框**：每个选项前有 Checkbox
- **全选/部分选**：支持父级全选/半选状态
- **已选标签**：输入框中显示已选项的标签

### 4. 懒加载级联

**动态加载**
- **按需加载**：点击展开时才加载下级数据
- **加载状态**：显示 Loading 图标
- **缓存机制**：已加载的数据缓存避免重复请求

## 九、实现建议（开发参考）

### 基本用法

```tsx
<Cascader
  value={selectedValue}
  placeholder="请选择省/市/区"
  options={cascaderOptions}
  onChange={handleChange}
  displayRender={(labels) => labels.join('/')}
/>
```

### 数据结构

```typescript
interface CascaderOption {
  label: string;          // 显示文本
  value: string | number; // 选项值
  children?: CascaderOption[]; // 子选项
  disabled?: boolean;     // 是否禁用
}

// 示例数据
const options = [
  {
    label: '青海省',
    value: 'qinghai',
    children: [
      {
        label: '西宁市',
        value: 'xining',
        children: [
          { label: '城区', value: 'chengqu' },
          { label: '城西区', value: 'chengxi' },
          { label: '城中区', value: 'chengzhong' },
        ]
      }
    ]
  }
];
```

### 样式关键点

- **列布局**：使用 Flexbox 或 Grid 实现多列布局
- **滚动**：每列独立滚动，使用 `overflow-y: auto`
- **高亮状态**：使用 `:hover` 和 `active` 类控制
- **展开动画**：使用 `transition` 添加平滑展开动画
- **右箭头**：使用 Icon 组件或 CSS `::after` 伪元素

## 十、与其他组件的关系

### Cascader vs Select

| 特性 | Cascader | Select |
|------|----------|--------|
| **层级** | ≥2 级 | 1 级（扁平） |
| **展示方式** | 多列展开 | 单列下拉 |
| **适用场景** | 层级数据 | 平铺数据 |
| **路径显示** | ✅ 显示完整路径 | ❌ 只显示选中项 |

### Cascader vs TreeSelect

| 特性 | Cascader | TreeSelect |
|------|----------|------------|
| **展示方式** | 多列并排 | 树形结构 |
| **适用层级** | 2-4 级 | 任意层级 |
| **空间占用** | 横向较宽 | 纵向较深 |
| **选择方式** | 逐级展开 | 展开/折叠节点 |

### 选择指南

- **层级清晰、层级少（2-3级）** → **Cascader**
- **层级深、层级不固定** → **TreeSelect**
- **无层级关系** → **Select**
- **选项很少（≤5个）** → **Radio**

## 十一、典型实现示例（省市区）

### 示例代码

```tsx
import { Cascader } from '@/components';
import { useState } from 'react';

const AddressSelector = () => {
```

## 十二、可访问性（Accessibility）

### ARIA 属性

- **role="combobox"**：标识为组合框
- **aria-expanded**：标识展开状态
- **aria-haspopup="listbox"**：标识有弹出列表
- **aria-activedescendant**：标识当前激活的选项

### 键盘导航

| 按键 | 功能 |
|------|------|
| **Enter/Space** | 打开/关闭面板 |
| **↑/↓** | 在当前列中上下移动 |
| **←/→** | 在列之间左右切换 |
| **Enter** | 选择当前高亮项 |
| **ESC** | 关闭面板 |
| **Tab** | 移动焦点到下一个元素 |

### 屏幕阅读器

- 输入框应有清晰的 `aria-label` 或 `label` 标签
- 选项变化时应有语音提示
- 路径变化时应读出完整路径

---

**总结**：Cascader 级联选择器是处理层级数据的高效组件，特别适合省市区选择、组织架构选择等场景。通过清晰的多列布局和即时反馈，为用户提供直观的层级选择体验。
