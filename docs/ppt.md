# 山东威海临港家庭数仓建设方案功能要点梳理

根据项目演示PPT内容，梳理以下核心功能模块与业务场景需求。

## 第一部分：数仓建设总体思路

### 1. 总体概念与目标
*   **核心理念**：从“专项数据”向“家庭融合感知集合”的转换。
*   **建设目标**：解决数据分散、口径不一问题，构建“房—户—人”三位一体的动态数据库，实现数据全生命周期闭环。

### 2. 数据构成与来源治理
*   **四全数据构建**：整合 **人、户、房、企、事、物** 全要素数据，结合 GIS 地理信息。
*   **多源数据接入**：
    *   **城市大脑**：通过接口自动拉取基础数据。
    *   **手工填报**：网格员/基层人员移动端录入。
    *   **批量导入**：Excel 表格数据清洗与导入。
*   **数据清洗治理**：建立清洗规则，去除重复、纠正错误（如身份证/电话校验），形成高质量基础库。

### 3. “人-房-户”家庭数据底座
*   **标准地址库**：构建“楼栋-单元-楼层-户口-人员”的标准多层级地址体系。
*   **人房户关系模型**：
    *   将分散的单项数据重构为“人-房”强关联模型。
    *   通过户籍、居住信息，自动生成以“家庭”为单位的关系网。
*   **全貌管理与审计**：提供全视角的家庭画像，支持对历史数据变更的追溯（时光轴）。

### 4. 标签体系与人员标签大模型
*   **标签生成与类型**：
    *   **基础标签**（属性类）：性别、年龄、户籍等。
    *   **规则标签**（统计类）：独居老人、学龄儿童等（基于设定规则自动打标）。
    *   **智能标签**（AI生成）：通过大模型分析非结构化文本生成标签。
*   **标签管理机制**：支持标签的增删改查、分类管理、权限控制。
*   **标签应用**：支持基于标签的人员筛选、群体分析、隐患预警。

### 5. 平台、大屏与移动端能力
*   **可视化大屏 (Dashboard)**：
    *   展示人口总量、结构、流动趋势。
    *   通过 GIS 地图展示人房分布热力图。
*   **Web管理端**：提供数据录入、审核、查询、标签管理、系统配置等完整功能。
*   **移动端 (山东通接入)**：
    *   面向基层网格员。
    *   支持现场采集、拍照上传、快速核查。

### 6. 数据安全与权限管理
*   **全栈安全防护**：数据加密、传输加密、防攻击。
*   **精细权限管控**：基于“角色+辖区”的权限隔离，确保用户只能看到授权范围内的数据。
*   **全程审计**：记录所有查询、导出、修改操作日志，支持安全溯源。

## 第二部分：家庭数仓应用场景

### 1. 网格员减负赋能
*   **电子记事本**：替代纸质台账，支持网格员随时随地记录走访信息，数据自动同步。
*   **“时光轴”与历史追溯**：记录人员/房屋的历史变更轨迹（如搬家记录、标签变更记录），避免“前任数据”丢失。

### 2. 精准关爱服务
*   **老人关爱体系**：识别独居、高龄、失能老人，结合水电气数据或走访记录，提供主动关怀。
*   **儿童扶助机制**：识别学龄儿童、留守儿童，关注入学情况与成长环境。
*   **困难家庭帮扶**：基于家庭收入与标签，自动识别低保/特困家庭，辅助政策精准落地。

### 3. 社区安全与风险防控
*   **重点人群管理**：关注精神障碍患者、吸毒人员、矫正人员等，实时更新动态。
*   **矛盾发现与化解**：整合 12345 诉求数据，分析邻里纠纷、家庭矛盾，实现早发现早化解。
*   **安全隐患识别**：通过走访记录与物联设备，识别群租房、消防隐患等。

### 4. 社群关系治理与矛盾化解
*   **法定亲属与居住关系图谱**：基于户籍和同住信息，自动生成家庭关系树。
*   **正向关系标注（请援兵）**：记录邻里互助、志愿者等正向关系，关键时刻可寻求帮助。
*   **负向关系预警（防冲突）**：记录过往纠纷、报警记录，生成“冲突预警”，避免矛盾激化。

### 5. 重点人员三色分级
*   **红黄绿三色定级**：基于“风险标签”自动计算风险等级（红=高危，黄=关注，绿=正常）。
*   **动态调整**：随着走访情况和事件发生，风险等级动态变化。
*   **高危优先**：红色人员在网格员任务列表中置顶，强制要求高频走访。

### 6. 社区专属知识库
*   **非结构化数据沉淀**：将网格员的“民情日记”、走访记录等文本数据转化为知识。
*   **智能问答助手**：网格员可通过自然语言提问（如“XX小区有哪些独居老人？”），系统基于知识库自动回答。

### 7. 人口与就业态势研判
*   **人口结构分析**：年龄分布、性别比例、老龄化趋势分析。
*   **就业失业监测**：基于社保或自主申报数据，识别失业人员，提供就业政策支持。

### 8. 应急联动与快速摸排
*   **极端天气应对**：在地图上快速定位脆弱人群（老人、残障人士）与重点隐患点（危房）。
*   **一键通知/上门**：灾害发生时，生成紧急排查名单，辅助快速转移或救助。
