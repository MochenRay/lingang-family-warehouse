# 临港家庭数仓 Phase 6 简历证据映射

> 日期：2026-04-22
> 对应任务：`T65`
> 用途：把公网在线演示口径、页面证据和验证文档对齐

## 1. 使用原则

- 简历里的每一条描述，都必须能在公网链接或正式验证文档里找到证据
- “在线演示”必须对应真实外网入口，不再使用“可重复部署包”替代
- 真实大模型能力和受控样例能力要分开表述

## 2. 推荐简历 Bullet

### Bullet 1：产品与业务结构

> 主导社区治理智能中台在线演示系统的产品结构设计，围绕“驾驶舱研判 -> 对象画像 -> 处置闭环 -> 移动端执行”搭建 Web 管理端与移动端工作台双端主链。

### Bullet 2：AI 能力设计

> 将 AI 能力拆分为数据画像、研判调度、社工助手三类业务内嵌能力，落到画像摘要、风险提示、待办建议、走访记录与政策/公文辅助等具体动作，而不是停留在孤立聊天页。

### Bullet 3：交付与上线

> 将高保真前端原型继续重构为可公网访问、可自由浏览、可恢复的在线演示系统，补齐统一后端、演示数据、恢复 runbook、外网验收和正式验证文档。

### Bullet 4：部署与发布

> 设计并落地“全栈真相层仓库 + 前端发布投影仓”的部署结构，前端通过 Vercel 发布到自定义域名，后端和数据库部署在 Railway 上，并完成公网外链验收。
