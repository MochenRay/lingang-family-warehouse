# 临港家庭数仓 Phase 5 链接交付说明

> 日期：2026-04-18
> 对应任务：`T53`
> 当前状态：预上线交付说明

## 1. 当前交付口径

当前项目的准确口径是：

- **可重复部署的演示环境**
- **可作为作品集链接提供**
- **可支持常规自由浏览和定向演示**

当前还不是：

- 正式公网长期运营站点
- 需要账号密码登录的业务系统

## 2. 当前可交付入口

### 本机演示入口

- Web：`http://127.0.0.1:4173`
- API 健康检查：`http://127.0.0.1:4173/api/health`

### 当前默认首屏

- `综合统计驾驶舱`

### 当前默认移动端入口

- 首页 CTA：`体验移动端主链`
- 侧边栏入口：`打开移动端工作台`

## 3. 发链接时建议附带的说明

### 简短版

> 这是我做的一个社区治理智能中台 Demo，Web 端和移动端都可以浏览。建议先看首页驾驶舱，再点人口管理、房屋管理、矛盾调解，最后体验移动端工作台。

### 标准版

> 这是一个可在线演示的网格治理智能中台作品。建议先从首页驾驶舱建立全景认知，再进入人口管理、房屋管理和矛盾调解看核心链路，最后点击移动端工作台体验一线执行侧。当前是演示环境，不需要登录。

## 4. 推荐浏览顺序

### 自由浏览入口

推荐先点：

1. `综合统计驾驶舱`
2. `人口管理`
3. `房屋管理`
4. `矛盾调解`
5. `移动端工作台`

### 定向演示入口

如果是你带着面试官看，建议顺序：

1. 驾驶舱开场
2. 人口管理看对象画像
3. 房屋 / 人房关系看空间治理
4. 矛盾调解看处置链
5. 移动端待办 -> 人员详情 -> 走访记录

## 5. 当前无需提供的东西

- 账号密码
- 角色切换说明
- 权限申请流程

原因：

- 当前是公开演示环境，不是用户体系产品

## 6. 如果环境被写脏，如何恢复

最短路径：

```bash
bash scripts/demo_reset.sh
```

如果需要完整重启：

```bash
bash scripts/demo_up.sh
bash scripts/demo_reset.sh
bash scripts/demo_health_check.sh
```

## 7. 当前不能对外承诺的事情

- 不能说“公网已稳定上线”
- 不能说“这是生产系统”
- 不能说“所有 AI 页都是真实大模型联动”

更准确的说法是：

- 这是一个可在线演示、可重复部署、可用于作品集投递的 Demo 环境

## 8. 交付给外部前的最后检查

发链接前至少确认：

1. 首页能打开
2. `/api/health` 返回正常
3. 首页 CTA 与移动端入口可见
4. 如有需要，先执行一次 `demo_reset.sh`
