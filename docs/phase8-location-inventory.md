# Phase 8 Location Inventory

## 事实来源摘要

- 烟台市政府转载山东省政府通知：2020-06-05 国务院批复撤销蓬莱市、长岛县，设立烟台市蓬莱区。参考：`https://www.yantai.gov.cn/art/2020/6/23/art_34892_2761640.html`
- 山东省民政公告口径：烟台市蓬莱区行政区划代码为 370614，并列有登州街道、紫荆山街道、蓬莱阁街道等街道。参考：`https://sdxw.iqilu.com/share/YS0yMS02OTcxMTU0.html`
- 烟台政务材料可确认蓬莱区登州街道海梦苑社区、东城社区等社区服务点名称。参考：`https://www.yantai.gov.cn/art/2024/2/18/art_11800_3173051.html`
- 本次只把演示运行态收口到烟台/蓬莱口径；未把无法逐条确认的街道、社区写成官方事实。
